# AI 宠物寄养管家 · 使用说明

## 一、这是什么

一个接入 DSH（deepseek-harness-java）的宠物寄养连锁 AI 助手。前端是运营工作台，右侧 AI 助手可以直接帮你查房型、查寄养师、预订寄养、查订单、看运营数据——全程自然语言，无需点菜单。

## 二、启动步骤

1. **启动业务应用**（端口 18113）：
   ```bash
   SERVER_PORT=18113 java -jar p-app/target/p-app-1.0.0-SNAPSHOT.jar
   ```
2. **确认 DSH 已运行**（端口 8090）且 `boarding-copilot` 插件已安装激活：
   ```bash
   curl -s http://127.0.0.1:8090/api/harness/plugins | grep boarding-copilot
   ```
3. **打开工作台**：浏览器访问 http://127.0.0.1:18113

## 三、AI 能做什么（试试这些话）

| 你说 | AI 做 |
|------|-------|
| 「猫寄养一天多少钱？有什么房型？」 | 调 `room_list`，列出房型单价与优惠 |
| 「有哪些寄养师？擅长什么？」 | 调 `keeper_list`，返回特长与评分 |
| 「帮我预订金毛「旺财」住豪华大床房 5 天，周五 10:00 入住，乐先生 13800111111」 | 调 `book`，**先复述要素请你确认**，确认后预订并给单号 |
| 「查一下订单 P4002 的状态」 | 调 `order_info`，返回详情与状态 |
| 「今天整体运营情况怎么样？」 | 调 `stats`，订单/待住夜数/建议一览 |

## 四、业务规则

- **预订确认制**：AI 预订前必须复述宠物、房型、天数、总价、入住日期，经你确认后才真正下单。
- **编号规则**：订单号 `P4001+`。
- **默认寄养师**：预订未指定寄养师时默认分配小满（K01，猫咪行为照护）。
- **优惠规则**：住满 7 天自动 9 折；度假托管月住 1880 元/30 天含洗护 2 次。
- **入住要求**：需上传疫苗证明；发情期/孕期宠物不接收。
- **服务承诺**：寄养师每日视频汇报；接宠时附赠洗护 8 折券。

## 五、常见问题

**Q：AI 一直显示「…」不动？**
AI 可能在调用 `ask_user_question` 等待你补充信息（如缺少入住日期）。把信息补齐重发即可；若仍卡住，等待约 1-2 分钟或重启 DSH 后重试。

**Q：插件激活失败 / 调用了旧工具？**
先卸载再重装：`POST /api/harness/plugins/boarding-copilot/uninstall`，删除 `~/.dsh/standalone/plugins/boarding-copilot.jar` 残留，重新 install + activate，并重启 DSH 以清空会话缓存。

**Q：换端口怎么改？**
应用端口：`SERVER_PORT=xxx` 环境变量；插件连应用端口：环境变量 `BOARDING_APP_BASE_URL`（默认 `http://127.0.0.1:18113`）。
